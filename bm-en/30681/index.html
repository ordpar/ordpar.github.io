kode II homograph 2

noun masculinesubstantiv hankjønn

a code · a PIN, a passcode

InflectionVis bøyning

EtymologyOpphav

gjennom fransk eller engelsk, fra latin codex; jamfør kodeksa codex, a code of rules through French or English, from Latin codex; compare kodeksa codex, a code of rules

Senses and Example SentencesBetydning og bruk

  1. (fortegnelse over) ord, bokstavkombinasjoner, tall eller andre symboler som brukes i skriftlige og muntlige meddelelser for å gjøre innholdet uforståelig for uvedkommende, for å spare plass eller for å få et standardisert, lettkjennelig informasjonssystem (a list of) words, letter combinations, numbers or other symbols used in written and spoken messages to make the content unintelligible to outsiders, to save space, or to give a standardised, easily recognised system of information
    • i Forsvaret sendes ofte meldinger i kode in the armed forces, messages are often sent in code
    • kjenne koden to know the code
    • varer prises nå mer og mer med kode goods are now more and more often priced by code
    • klær skal ha kode for vask clothes must carry a washing code
  2. tallkombinasjon som noe må innstilles på for å kunne åpnes eller gi tilgang a combination of numbers that something has to be set to in order to open it or give access
    • koden til bankkortet the PIN for the bank card
    • koden til mobiltelefonen the passcode for the mobile phone
    • kjenne koden til safen to know the combination to the safe
  3. sett av entydige regler for den måten data blir representert ved tegnene i et tegnsett a set of unambiguous rules for the way data is represented by the characters of a character set
    • alfabetisk kode alphabetic code
    • numerisk kode numeric code
  4. instruksjon i et dataprogram som definerer hva programmet skal gjøre an instruction in a computer program that defines what the program is to do
  5. sett av uskrevne regler for oppførsel og sosial omgang a set of unwritten rules for behaviour and social interaction
    • ikke skjønne kodene for sosialt samvær to not grasp the codes of social interaction
