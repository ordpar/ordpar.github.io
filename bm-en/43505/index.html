Senses and Example SentencesBetydning og bruk

  1. om øverste del;
    i ord som overarm og overklasse
  2. om bevegelse ovenfra og ned på, i retning av, videre enn og lignende;
    i ord som overfalleto assault, to attack, to set upon, overrisle og overskrideto exceed, to overstep, to go beyond
  3. om overordning;
    i ord som overlærer og overmenneskea superman, a superhuman, an Übermensch
  4. om høy grad;
    i ord som overbegeistret
  5. om for høy grad;
    i ord som overbelaste og overforbruk
