begivenhet

noun masculine or femininesubstantiv hankjønn eller hunkjønn

an event · an occasion

InflectionVis bøyning

PronunciationUttale

bejiˊvenhet

EtymologyOpphav

etter tysk Begebenheit, opprinnelig ‘det som skjer’; jamfør begito set off (only in fixed expressions) after German Begebenheit, originally ‘that which happens’; compare begito set off (only in fixed expressions)
