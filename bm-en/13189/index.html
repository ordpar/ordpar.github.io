etablere

verb

to establish · to set up

Inflection

Etymology

gjennom fransk; fra latin stabilire ‘gjøre fast’through French; from Latin stabilire 'to make firm'

Senses and Example Sentences

starte, sette i gang;
grunnlegge (1)to found, opprette (1)to set upto start, to set in motion;
to foundgrunnlegge (1), to set upopprette (1)
  • etablere et selskapto set up a company
  • etablere rutiner for håndtering av farlig avfallto put routines in place for handling hazardous waste
  • etablere kontaktto establish contact

Set phrases

etablere seg
  1. stifte familie, få seg fast jobb, bolig og lignende;
    få en trygg og stabil posisjon    to start a family, get a permanent job, a home and so on;
    to gain a secure and stable position     Eng. phraseto settle down
    • vi flyttet ut av byen for å etablere osswe moved out of town to settle down
    • etablere seg i lokalsamfunnetto establish oneself in the local community
  2. starte firmato start a business Eng. phraseto set up shop
    • bedriften etablerte seg i utlandetthe company established itself abroad
