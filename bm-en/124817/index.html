formelt objekt

Senses and Example SentencesBetydning og bruk

trykklett ‘det’ som fungerer som objekt i en setning unstressed det 'it' serving as the object in a sentence see:Se: objektan object Eng. phrasedummy object
  • i setningen ‘du må ta det med ro’ er ‘det’ formelt objekt in the sentence du må ta det med ro 'you must take it easy', det 'it' is a dummy object
