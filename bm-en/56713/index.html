Senses and Example SentencesBetydning og bruk

  1. det å begynne på noe;
    begynnelsebeginning · start     the act of starting something;
    beginningbegynnelse
    • foretaket fikk en dårlig start the venture got off to a bad start
    • turen var vellykket helt fra starten the trip was a success right from the start
  2. det å starte (på signal) i en idrettskonkurranse the act of setting off (on a signal) in a sports competition
    • konkurransen fra start til mål the race from start to finish
    • 15 lag stilte til start i stafetten 15 teams lined up at the start of the relay
    • hele feltet fikk en god start the whole field got off to a good start
    • være raskt ute i starten to be quick off the mark at the start
  3. det å få i gang (motor, kjøretøy eller lignende) the act of getting (an engine, vehicle or the like) going
    • få start på motoren to get the engine started
  4. sted eller punkt der noe begynner;
    utgangspunktstarting point · basis, premise     place or point where something begins;
    starting pointutgangspunkt
    • vi måtte rykke tilbake til start we had to go back to the start
    • ved starten av året så ting vesentlig bedre ut at the start of the year things looked considerably better
