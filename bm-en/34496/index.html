løpende

adjectiveadjektiv

ongoing · continuous · running

InflectionVis bøyning

EtymologyOpphav

av løpeto run from løpeto run

Senses and Example SentencesBetydning og bruk

  1. som løper who is running
    • bilen passerte en løpende kvinne the car passed a running woman
    brukt som adverb: used as an adverb:
    • hunden kom løpende the dog came running
  2. som foregår kontinuerlig;
    som stadig kommer igjen     which goes on continuously;
    which keeps recurring
    • løpende utgifter running costs
    • det var løpende dialog mellom partene there was ongoing dialogue between the parties
    • de var i løpende kontakt med myndighetene they were in continuous contact with the authorities
    brukt som adverb used as an adverb
    • holde noen løpende orientert to keep someone continuously informed
  3. som utgjør én målbar enhet av en viss utstrekning eller lengde which makes up one measurable unit of a certain extent or length
    • betale pr. løpende meter to pay per running metre
    • få en godtgjørelse pr. løpende kilometer to receive compensation per running kilometre

Set phrasesFaste uttrykk
