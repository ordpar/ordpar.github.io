løpende

adjective

ongoing · continuous · running

Inflection

Etymology

av løpeto runfrom løpeto run

Senses and Example Sentences

  1. som løperwho is running
    • bilen passerte en løpende kvinnethe car passed a running woman
    brukt som adverb:used as an adverb:
    • hunden kom løpendethe dog came running
  2. som foregår kontinuerlig;
    som stadig kommer igjen    which goes on continuously;
    which keeps recurring
    • løpende utgifterrunning costs
    • det var løpende dialog mellom partenethere was ongoing dialogue between the parties
    • de var i løpende kontakt med myndighetenethey were in continuous contact with the authorities
    brukt som adverbused as an adverb
    • holde noen løpende orientertto keep someone continuously informed
  3. som utgjør én målbar enhet av en viss utstrekning eller lengdewhich makes up one measurable unit of a certain extent or length
    • betale pr. løpende meterto pay per running metre
    • få en godtgjørelse pr. løpende kilometerto receive compensation per running kilometre

Set phrases

på løpende bånd som går i ett uten avbrytelse;

continuouslyfortløpende Eng. phraseone after another
  • meldingene kom på løpende båndthe reports came in a steady stream
