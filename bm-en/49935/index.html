samme

determiner demonstrative

same

Etymology

norrønt samiOld Norse sami

Senses and Example Sentences

  1. som er identisk med noe som er nevnt eller underforståttidentical with something mentioned or understood
    • bruke samme dressen dag etter dagto wear the same suit day after day
    • det hendte samme dagit happened the same day
    • de fortsatte på samme måtethey carried on in the same way
    brukt som substantiv:used as a noun:
    • gjøre det samme om igjento do the same thing over again
    • takk, det samme!thanks, same to you!
  2. som er som før;
    uforandretunchanged, unaltered    the same as before;
    unchangeduforandret
    • du er samme guttenyou are the same boy as ever
    • verden er den samme overaltthe world is the same everywhere
    • tilstanden var den sammethe condition was the same
  3. som en har, bruker eller gjør sammen;
    felles (II)shared · common · joint · mutual    which one has, uses, or does jointly;
    sharedfelles (II)
    • bo under samme takto live under the same roof
    • gå samme veito go the same way
    • de kjørte med samme fartthey drove at the same speed
  4. om tid: brukt for å uttrykke at noe skjer samtidigof time: used to express that something happens simultaneously
    • i samme stundat the same moment
    • på samme tidat the same time
